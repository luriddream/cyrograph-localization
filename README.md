# 🌐 CYROGRAPH Localization

Localization project for the game [CYROGRAPH](https://luriddream.itch.io/cyrograph).

## How to contribute

All translations live in [localization.csv](localization.csv). To add a new language:

1. Open `localization.csv` in a spreadsheet editor or text editor of your choice.
2. Add a new column next to the existing language columns.
3. Use a valid language name as the column header (e.g. `de`, `es`, `fr`).
4. Fill in the translations row by row, matching the existing keys.
5. Open a Pull Request with your changes.
6. In the PR description, mention who should be credited as the translation author (name, nickname, and/or social link).

Thank you for helping make the game available to more players!
